## ✨ О проекте

**MiryoLove AI** — независимый ИИ-проект, созданный Miryo Bun и посвящённый разработке дружелюбного ИИ-ассистента и исследованию языковых моделей.

Проект ориентирован на помощь в программировании, обучение, технические объяснения и взаимодействие на нескольких языках.

## 💗 MiryoLove-7B

MiryoLove-7B основана на **Qwen2.5-7B-Instruct**, первоначально разработанной Qwen / Alibaba Cloud.

- **Базовая модель:** Qwen2.5-7B-Instruct
- **Метод дообучения:** LoRA
- **Опубликованные веса:** объединённые веса FP16
- **Количество параметров:** около 7 миллиардов
- **Языки:** английский и русский

Эти сведения основаны на описании проекта и требуют проверки по файлам модели и записям об обучении.

MiryoLove AI — независимый проект, не являющийся официальным выпуском Qwen или Alibaba Cloud.

## 🌟 Возможности

- 💻 **Программирование:** Python, C, C++, Java и Assembly.

## 🚀 Начало работы

### 1. Требования

- Python 3.10 или новее
- PyTorch
- Transformers
- Accelerate
- Bitsandbytes
- Совместимое оборудование и конфигурация загрузки модели

### 2. Установка зависимостей

```bash
pip install torch transformers accelerate bitsandbytes
```

### 3. Настройка модели

```bash
export MIRYO_MODEL=MiryoBun/MiryoLove-7B
```

### 4. Запуск MiryoLove AI

```bash
python miryolove_ai.py
```

Требования к оборудованию зависят от конфигурации инференса, квантования, длины контекста и доступной памяти. Перед запуском ознакомьтесь с актуальными инструкциями в репозитории модели.
