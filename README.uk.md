## ✨ Про проєкт

**MiryoLove AI** — незалежний ШІ-проєкт, створений Miryo Bun і присвячений розробці дружнього ШІ-асистента та дослідженню мовних моделей.

Проєкт зосереджений на допомозі з програмуванням, навчанні, технічних поясненнях і взаємодії кількома мовами.

## 💗 MiryoLove-7B

MiryoLove-7B базується на **Qwen2.5-7B-Instruct**, спочатку розробленій Qwen / Alibaba Cloud.

- **Базова модель:** Qwen2.5-7B-Instruct
- **Метод донавчання:** LoRA
- **Опубліковані ваги:** об'єднані ваги FP16
- **Кількість параметрів:** близько 7 мільярдів
- **Мови:** англійська, російська, українська

Ці відомості ґрунтуються на описі проєкту та потребують перевірки за файлами моделі й записами про навчання.

MiryoLove AI — незалежний проєкт, який не є офіційним випуском Qwen або Alibaba Cloud.

## 🚀 Початок роботи

### 1. Вимоги

- Python 3.10 або новіший
- PyTorch
- Transformers
- Accelerate
- Bitsandbytes
- Сумісне обладнання та конфігурація завантаження моделі

### 2. Встановлення залежностей

```bash
pip install torch transformers accelerate bitsandbytes
```

### 3. Налаштування моделі

```bash
export MIRYO_MODEL=MiryoBun/MiryoLove-7B
```

### 4. Запуск MiryoLove AI

```bash
python miryolove_ai.py
```

Вимоги до обладнання залежать від конфігурації інференсу, квантування, довжини контексту та доступної пам'яті. Перед запуском ознайомтеся з актуальними інструкціями в репозиторії моделі.
