## 📖 Вступ

### 💗 MiryoLove-7B

MiryoLove-7B — мовна модель, яка, згідно з описом проєкту, базується на **Qwen2.5-7B-Instruct**, спочатку розробленій Qwen / Alibaba Cloud.

За інформацією проєкту, модель було донавчено за допомогою LoRA, а ваги об’єднано у форматі FP16.

MIRYOLOVE AI — незалежний проєкт, а не офіційний випуск Qwen або Alibaba Cloud.

### ✨ Основні можливості

- **Допомога з програмуванням:** Python, C, C++, Java та Assembly.
- **Освітня підтримка:** пояснення з програмування та практичні завдання.
- **Технічний переклад:** передбачена підтримка англійської, української та російської мов.
- **Ресурси моделі:** файли й інформація про модель на Hugging Face.
- **Незалежна розробка:** розвиток під назвою MIRYOLOVE AI.
